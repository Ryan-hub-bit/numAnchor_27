# NumAnchor Artifact

This repository is the code-only artifact branch for `NumAnchor`. Large datasets, vocabularies, tokenizers, and checkpoints are staged separately in the Zenodo artifact archive.

Download the data/model artifact from Zenodo:

https://zenodo.org/records/19748674

Original upstream repositories used as bases:

- BERT-style baseline: https://github.com/codertimo/BERT-pytorch and https://github.com/palmtreemodel/transformer-evaluation
- PalmTree: https://github.com/palmtreemodel/PalmTree
- JTrans: https://github.com/vul337/jTrans
- StateFormer: https://github.com/CUMLSec/stateformer
- Trex: https://github.com/CUMLSec/trex

## Artifact Layout

Set the artifact root before running commands:

```bash
export NUMANCHOR_ARTIFACT_ROOT=/path/to/NumAnchor_artifact/staging
```

Expected staged layout:

```text
$NUMANCHOR_ARTIFACT_ROOT/
  artifact_manifest.json
  data/
    shared_stateformer_x64/
    bert_function_x64/
    palmtree_x64/
    jtrans_full/
    stateformer_strict_opt/
    trex/
  models/
    bert_function/
    palmtree/
    jtrans/
    stateformer/
    trex/
```

Model filenames are intentionally neutral, for example `numanchor_pretrain.pt` and `numanchor_finetune.pt`; they do not expose training epoch counts. Function blocks and ground-truth files are packaged, while retrieval pools are generated by reviewers with `scripts/artifact/generate_pools.py`.

Each top-level project directory includes an `environment.yml` for creating the component-specific runtime environment.

## Staging And Self-Check

The private source-selection file lives outside Git:

```bash
python scripts/artifact/stage_numanchor_artifact.py \
  --selection /path/to/private/source_selection.local.json \
  --dest "$NUMANCHOR_ARTIFACT_ROOT" \
  --overwrite

python scripts/artifact/self_check.py \
  --artifact-root "$NUMANCHOR_ARTIFACT_ROOT" \
  --cleanup-pools
```

The self-check validates the manifest, scans public paths for non-anonymous names, and generates small deterministic pools from packaged ground-truth files.
